# Personal Portfolio & ML Engineering Showcase

This repository houses the source code for my personal portfolio website, showcasing my work as a Machine Learning Engineer focused on computer vision, NLP, and MLOps infrastructure.

🔗 **Live Link:** https://ycusif.github.io

## 🚀 Key Highlights Demonstrated
* **Production Focus:** Designed with a clean, responsive UI emphasizing system latency, reproducibility, and end-to-end ML deployment metrics.
* **Performance-First Architecture:** Clean HTML5, CSS3, and vanilla JavaScript with zero heavy external framework dependencies for near-instantaneous load times and optimal SEO performance.
* **Fully Responsive:** Smooth layout transitions optimized across desktop, tablet, and mobile viewport breakpoints.

## 🛠️ Technical Stack
* **Markup & Structure:** HTML5
* **Styling & Animations:** CSS3 (Custom properties, Flexbox/Grid, Intersection Observer API for fade-in animations)
* **Interactivity:** Vanilla JavaScript

## 📁 Repository Structure
* `index.html` - The core application entry point containing all monolithic structures, styles, and viewport scripts.
* `README.md` - Repository documentation.
